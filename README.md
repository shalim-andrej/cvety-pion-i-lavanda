# Пион и лаванда — сайт студии цветов

Одностраничный промо-сайт цветочной студии: каталог букетов, этапы работы, отзывы и форма заказа. Задача страницы — привести гостя от первого экрана до заявки за одну минуту.

**Демо:** [shalim-andrej.github.io/cvety-pion-i-lavanda](https://shalim-andrej.github.io/cvety-pion-i-lavanda/)

## О проекте

Концепт-сайт вымышленной студии «Пион и лаванда» — портфолио-кейс для ниши с быстрой покупкой. Оффер «доставка за час» вынесен в заголовок браузера и первый экран, между каталогом и формой — блок доверия: этапы работы, студия, отзывы. Воронка короткая, путь до заявки — без лишних шагов.

Вёрстка написана с нуля, без конструкторов и фреймворков: чистые HTML, CSS и JavaScript.

## Структура страницы

| Блок | Задача |
|---|---|
| Первый экран | оффер «доставка за час» и переход к заказу |
| Букеты | каталог работ студии |
| Как мы работаем | этапы: заявка — сборка — доставка |
| Студия | фото и знакомство с командой |
| Отзывы | социальные доказательства |
| Заказать букет | форма заявки |

## Технологии

- **HTML5** — семантическая разметка: один блок = один смысл
- **CSS3** — Flexbox и Grid, адаптив от смартфона до широкого монитора
- **JavaScript (vanilla)** — вся интерактивность без внешних библиотек
- **Форма заявки** — минимум полей, чтобы не терять заказы
- **SEO-база** — `<title>` с оффером, `meta description`, логичная иерархия заголовков

## Запуск локально

```bash
git clone https://github.com/shalim-andrej/cvety-pion-i-lavanda.git
cd cvety-pion-i-lavanda
```

Откройте `index.html` в браузере — сборка и зависимости не нужны.
